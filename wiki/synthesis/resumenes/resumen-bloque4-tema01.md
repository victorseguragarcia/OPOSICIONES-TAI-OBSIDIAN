# 🔴 Resumen Tema 01 (Bloque 4): Administración de Sistemas Operativos Servidor

> [!repaso] ⚡ **Puntos Clave de Examen en 60 Segundos**
> Instalación, configuración y administración de Windows Server y distribuciones Linux (Debian, RHEL).

---

## 🟣 1. Síntesis Teórica y Conceptos Fundamentales

- **Linux**: `systemd` (`systemctl`, `journalctl`), Permisos SUID (4755), SGID (2775), Sticky Bit (1777), `umask 027` (dir 750 / arch 640). LVM (PV $\rightarrow$ VG $\rightarrow$ LV).
- **Windows Server**: Server Manager, PowerShell (`Set-ExecutionPolicy RemoteSigned`).
